# E-commerce Customer Retention and Cohort Analysis

## Project Overview
This project analyzes e-commerce customer purchasing behavior, repeat purchases, revenue, and customer retention using SQL and MySQL.

## Objectives
- Identify repeat and one-time customers.
- Analyze monthly and total revenue.
- Find top-selling products and categories.
- Identify high-value customers.
- Analyze customer first purchases and cohort patterns.

## Tools Used
- MySQL
- SQL
- GitHub

## Database Tables
1. Customers
2. Products
3. Orders
4. Order_Details

## SQL Concepts Used
- CREATE DATABASE and CREATE TABLE
- INSERT INTO
- SELECT and WHERE
- GROUP BY and HAVING
- Aggregate functions
- JOINs
- ORDER BY and LIMIT
- Date functions
- Cohort analysis fundamentals

## Business Analysis
The project includes 20 business questions covering revenue, customer purchases, products, categories, and order analysis, along with queries for first purchases, repeat customers, and one-time customers.

## Conclusion
This project demonstrates how SQL can be used to analyze customer purchasing behavior and e-commerce business performance to support data-driven decisions.
